# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/ping` | Show your ping and current server load | `` | `/<command>` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootping.use` | Use /ping | `true` |
| `rootping.admin` | Reload Root-Ping | `op` |
